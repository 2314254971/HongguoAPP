# 迭代计划

## 1.0.1（本次已修）

1. 播放器内选集点击无反应：对话框里的集数按钮漏了点击事件，已补上并支持当前集高亮。
2. 切集"解析中"空档：播到第 5 秒就开始后台解析下一集，剩余 8 秒时兜底重试；预解析命中时直接接管，不再显示解析浮层。
3. 搜索搜不到：`search()` 会按 `genre=203` 过滤，官网结果被滤空；改用电视版一直在用的 `searchAll()` 官网接口，失败再回退。

## 下一轮：播放体验（P0）

| 功能 | 做法 | 说明 |
| --- | --- | --- |
| 倍速 | `ExoPlayer.setPlaybackSpeed()`，0.75/1.0/1.25/1.5/2.0 | 半小时内可完成，档位存本地 |
| 手势 | 左侧上下滑调亮度、右侧调音量、横向滑进度 | 和上下滑切集做方向判定，避免冲突 |
| 连播 | 预解析提前到片头 3 秒 | 现在 8 秒；短剧集短，提前更稳 |

## 第二轮：账号与收藏（P1）

- 扫码登录：`core` 里 `WebLogin` + `QRCodeWriter` 已具备，只缺界面与登录态持久化。
- 登录后加载云端收藏/历史，与本地库合并（本地优先，冲突取时间较新）。
- 这一项价值最高：换机不丢片单。

## 第三轮：下载（P1）

- 复用 `RemoteVideo` 全量读取解密后的字节，写入应用私有目录，扩展名 `.mp4`。
- 需要：任务队列、进度、暂停/续传、失败重试、剩余空间检查。
- 只做本地离线观看，不做导出/分享；内容版权归平台。

## 第四轮：弹幕与评论（P2）

- 弹幕：`core` 已有 `TimedComments` 与弹幕签名，先做只读展示（滚动/顶部/底部、开关、透明度）。
- 评论：`CommentTransport` 可匿名读取，做详情页的评论区，只读、分页。
- 发送弹幕/评论需要签名与登录态，风险与工作量都更高，暂不做。

## 工程事项

- 真机回归清单：冷启动、弱网、切集、横竖屏、后台恢复。
